# Sales Management System

## Project Overview
The Sales Management System is a web-based application designed to help businesses efficiently manage their sales operations. This system allows users to track daily sales, manage menu items, and receive instant insights into business performance. Built with a modern UI, this application leverages Tailwind CSS for responsive and sleek design.

## Installation
To set up the Sales Management System locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/sales-management-system.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd sales-management-system
   ```

3. **Open the `index.html` file in your browser**:
   Simply double-click on the `index.html` file or open it using your preferred web browser.

4. (Optional) If you're looking to modify the project, consider setting up a local server, e.g., using Live Server extension in VSCode, for live reloading capabilities.

## Usage
- **Dashboard**: Upon opening the application, users will be greeted with a dashboard that summarizes today's sales data and recent sales activities.
- **Record Sale**: Navigate to the ‘Record Sale’ page to enter and submit new sales records. Users can select menu items, specify quantities, and see the total amount before submission.
- **Menu Management**: The menu management feature allows users to add, edit, and remove menu items, providing them with complete control over the products offered.

## Features
- User-friendly interface for easy navigation and operation.
- Daily sales tracking and reporting.
- Dynamic forms for recording sales and managing menu items.
- Responsive design ensuring compatibility across devices.
- Instant feedback (success messages) to users upon completing actions, such as recording a sale or adding a menu item.

## Dependencies
The project relies on the following libraries and frameworks:
- [Tailwind CSS](https://tailwindcss.com/) - For CSS styling.
- [Font Awesome](https://fontawesome.com/) - For icons.

These libraries are included via CDN links directly in the HTML files.
